## Содержательная переработка

Каждый из 9 разделов теперь содержит цель, теорию, исполняемый пример, типичные ошибки, мини-практику, вопрос самопроверки и краткий итог:

1. зачем Python используется в анализе данных;
2. структура Python-проекта;
3. типы данных и коллекции;
4. функции и контракты;
5. чтение CSV-файлов;
6. обработка пропущенных значений;
7. исключения и обработка ошибок;
8. тестирование функций;
9. простой pipeline обработки данных.

Для денежных значений зафиксирован `Decimal`. Строгая CSV-политика: первая невалидная строка вызывает `InvalidOrderError` с номером строки, частичный результат не возвращается, а успешный JSON содержит `errors: []`.
