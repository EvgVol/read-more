# Источники курса «ML-инженер»

Материалы курса написаны как авторские конспекты и практические задания. Ссылки ниже используются для проверки API, терминов и рекомендуемых рабочих приёмов.

| Тема | Официальный источник | Что проверяется |
|---|---|---|
| Python | https://docs.python.org/3/tutorial/ | структуры данных, функции, модули, исключения, классы, окружения |
| NumPy | https://numpy.org/doc/stable/user/quickstart.html | `ndarray`, `shape`, `dtype`, broadcasting, векторные операции |
| Pandas | https://pandas.pydata.org/docs/getting_started/intro_tutorials/ | чтение данных, выборки, объединения, пропуски, группировки |
| Scikit-learn | https://scikit-learn.org/stable/user_guide.html | preprocessing, model selection, metrics, pipelines, модели |
| PyTorch | https://docs.pytorch.org/tutorials/ | tensors, datasets, model building, autograd, training |
| PostgreSQL 13 | https://www.postgresql.org/docs/13/ | SQL, joins, aggregations, indexes, transactions, `EXPLAIN` |
| Docker | https://docs.docker.com/get-started/ | images, containers, Dockerfile, Compose, networking |
| FastAPI | https://fastapi.tiangolo.com/tutorial/ | path operations, validation, dependencies, deployment |
