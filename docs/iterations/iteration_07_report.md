# Iteration 07 — агрегированный прогресс quiz по курсу

Статус: **DONE**

## Цель

Дать студенту обзор освоения quiz по всему курсу, не смешивая его с прогрессом чтения и завершением пяти этапов урока.

## Что сделано

- Добавлен сервис `course_quiz_progress`.
- В расчёт входят только уроки с опубликованными вопросами.
- Для каждого урока учитывается только последняя попытка текущего пользователя.
- В sidebar trainer отображаются:
  - количество успешно пройденных quiz;
  - общее количество quiz в курсе;
  - средний процент по последним попыткам.
- Если попыток нет, результат не считается нулевым — студент видит `0/N` и средний результат `0%`.
- Данные изолированы по пользователю.
- Запросы bounded и не зависят линейно от числа вопросов.

## Проверки

- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **63 теста OK**.
- В рабочей базе агрегат показывает 4 quiz-урока, 1 пройденный и средний результат 100%.
