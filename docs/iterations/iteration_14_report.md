# Iteration 14 — навигация и фильтры редакторского отчёта

Статус: **DONE**

## Цель

Сократить время проверки курса: редактор должен быстро перейти к нужному уроку и сразу увидеть только проблемные материалы.

## Что сделано

- В таблице аудита название каждого урока стало ссылкой на соответствующий экран обучения.
- Добавлены фильтры:
  - «Все уроки»;
  - «Только с замечаниями».
- Для пустого результата фильтра отображается понятное состояние «Все уроки прошли аудит — замечаний нет».
- Фильтр сохраняет общую сводку курса и меняет только список строк.
- В JSON-отчёт добавлены `module_id` и `lesson_id`, чтобы его можно было связать с интерфейсом и внешними инструментами.
- Стили фильтров и ссылок адаптированы под мобильную ширину.

## Проверки

- Владелец курса видит ссылки на уроки и фильтры.
- Фильтр `?filter=issues` корректно показывает пустое состояние при нулевом количестве замечаний.
- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **70 тестов OK**.
- Startup-аудит продолжает проходить: 7 модулей, 28 уроков, 84 quiz-вопроса.
