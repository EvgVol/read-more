# Iteration 11 — автоматический аудит учебного контента

Статус: **DONE**

## Цель

Добавить проверяемый quality gate для курса ML-инженера, чтобы неполные материалы или слабое покрытие quiz не попадали в запущенное приложение незаметно.

## Что сделано

- Добавлена команда `audit_ml_learning_content`.
- Аудит проверяет:
  - 7 модулей и 28 уроков;
  - наличие `LessonMaterial` у каждого урока;
  - непустые цели, практику и самопроверку;
  - объём теории каждого урока в диапазоне 6000–10000 слов;
  - обязательные разделы теории;
  - не менее 3 опубликованных quiz-вопросов на урок;
  - наличие трёх типов вопросов;
  - отсутствие дублирующихся позиций и формулировок.
- Команда подключена к Docker startup после всех seed-команд. При нарушении условий контейнер явно завершается с ошибкой аудита.
- End-to-end тест проверяет порядок запуска seed и успешное прохождение аудита после наполнения курса.

## Проверки

- `docker compose build web && docker compose up -d web nginx` — успешно.
- Startup-логи: `Аудит пройден: 7 модулей, 28 уроков, 84 quiz-вопросов.`
- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **65 тестов OK**.
- Рабочая база: **7 модулей, 28 уроков, 84 опубликованных вопроса**.
- HTTP-проверка trainer URL отвечает через nginx редиректом на авторизацию (`302`), что соответствует защищённому маршруту.
