# Iteration 06 — история попыток quiz

Статус: **DONE**

## Цель

Показать не только последний результат, но и динамику прохождения quiz, сохранив отдельность этой истории от пятишагового прогресса урока.

## Что сделано

- В trainer добавлен список до 10 последних попыток текущего пользователя по активному уроку.
- Для каждой попытки отображаются дата, процент, баллы и статус.
- Последняя попытка по-прежнему выделяется отдельным summary-блоком.
- Неуспешные попытки маркируются как «Повторить», успешные — как «Пройдено».
- История не доступна другому пользователю: выборка фильтруется по `user` и `lesson`.
- Список ограничен десятью записями и загружается одним bounded-запросом.

## Проверки

- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **62 теста OK**.
- После первой попытки отображается `История попыток (1)`.
- После второй попытки отображается `История попыток (2)` и статус неуспешной попытки.
- Результат сохраняется в рабочей базе после перезапуска контейнера.
