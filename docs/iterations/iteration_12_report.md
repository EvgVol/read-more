# Iteration 12 — редакторский отчёт и усиленный аудит

Статус: **DONE**

## Цель

Сделать результаты аудита полезными не только для startup quality gate, но и для редактора курса, который проверяет конкретные уроки и вопросы.

## Что сделано

- Команда `audit_ml_learning_content` получила два режима отчёта:
  - `--report` — читаемый список метрик по каждому уроку;
  - `--format=json` — чистый JSON для CI, админки или дальнейшей аналитики.
- Для каждого урока в отчёте видны объём теории, объём практики, число вопросов self-check, количество quiz-вопросов и покрытые типы.
- Усилена проверка quiz payload:
  - минимальная длина prompt и explanation;
  - непустые варианты ответов и уникальные option id;
  - корректные ссылки `correct_answers` на варианты;
  - ровно один правильный ответ для single;
  - отсутствие вариантов у short-вопросов;
  - положительное количество points.
- Усилена проверка материалов:
  - практика содержит не менее 20 слов;
  - self-check содержит минимум 3 вопроса;
  - resources содержат минимум 2 ссылки.
- Расширены практические задания в 9 уроках, которые не проходили новый порог объёма.
- Добавлены end-to-end проверки текстового и JSON-отчётов.

## Проверки

- Docker startup проходит полный аудит курса.
- `audit_ml_learning_content --format=json` возвращает валидный JSON:
  - 7 модулей;
  - 28 уроков;
  - 84 опубликованных quiz-вопроса;
  - 0 замечаний.
- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **66 тестов OK**.
