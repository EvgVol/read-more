# Iteration 09 — прогресс quiz по модулям

Статус: **DONE**

## Цель

Показать детализацию общего quiz-прогресса по модулям, чтобы студент видел не только итог по курсу, но и конкретные зоны, которые уже освоены.

## Что сделано

- Добавлен сервис `module_quiz_progress`.
- Для каждого модуля рассчитываются:
  - количество quiz-уроков;
  - количество попыток;
  - количество успешно пройденных тестов;
  - средний процент по последним попыткам.
- В списке модулей trainer появился компактный индикатор `Тесты: X/Y · Z%`.
- В расчёт попадает только последняя попытка каждого урока.
- Данные ограничены текущим пользователем.
- Загрузка выполняется пакетно без запроса на каждый модуль или вопрос.

## Проверки

- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **64 теста OK**.
- Runtime trainer показывает одновременно курс `1/28` и Python-модуль `1/4`.
- Performance-тест trainer проходит в bounded query budget.
