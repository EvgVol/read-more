# Iteration 03 — пилотное заполнение первого урока

Статус: **DONE**

## Цель

Проверить новый блочный интерфейс на реальном содержимом курса и создать повторяемый способ публикации первого пилотного урока без удаления legacy-материала.

## Что сделано

- Добавлена команда `seed_ml_lesson_blocks`.
- Команда находит урок `Python для анализа данных` в курсе `ml-inzhener`.
- Создаются или обновляются пять опубликованных блоков:
  - основная theory;
  - локальная схема потока данных;
  - исполняемый пример Python;
  - локальная схема цикла проверки;
  - summary с контрольным вопросом.
- Заполнение идемпотентно: повторный запуск не создаёт дубликаты.
- Legacy `LessonMaterial` сохранён и используется как источник основной теории.
- Пилот применён к рабочей базе.
- `seed_ml_course` переведён с удаления модулей и уроков на идемпотентное обновление. Это сохраняет идентификаторы уроков, `LessonMaterial`, `LessonBlock` и `LessonProgress` после перезапуска контейнеров.
