# Iteration 15 — категории замечаний и экспорт аудита

Статус: **DONE**

## Цель

Дать редактору быстрый способ понять типы проблем и вынести текущий список уроков в рабочий файл.

## Что сделано

- В отчёте появилась секция «Типы замечаний» с категориями:
  - Материалы;
  - Теория;
  - Практика;
  - Self-check;
  - Quiz;
  - Структура курса.
- Для каждого урока категории замечаний сохраняются в отчёте и показываются в строке таблицы.
- Добавлена кнопка «Скачать CSV».
- CSV учитывает активный фильтр `all`/`issues` и содержит модуль, урок, категории и полный текст замечаний.
- Экспорт защищён теми же правилами доступа, что и страница аудита.
- Для стабильного JSON-отчёта сохранена детализация категорий в summary.
