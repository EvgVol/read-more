# Iteration 10 — полноценные quiz для всей программы

Статус: **DONE**

## Цель

Сделать проверку знаний одинаково полезной для всей программы: каждый урок должен проверяться не одним поверхностным вопросом, а несколькими форматами.

## Что сделано

- Для всех 28 уроков опубликовано по 3 вопроса.
- Общий объём quiz — 84 вопроса.
- Для Python-модуля сохранены предметные вопросы по single-choice, multiple-choice и short-answer.
- Для остальных модулей добавлены:
  - базовый single-choice по ключевой концепции;
  - multiple-choice по инженерным практикам;
  - короткий ответ по теме урока.
- Существующая серверная проверка, история попыток и агрегированный прогресс работают без изменений.
- Seed остаётся идемпотентным и запускается при старте Docker.

## Проверки

- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **64 теста OK**.
- Рабочая база: **84 опубликованных вопроса**, покрытие **28/28 уроков**.
- Минимальное покрытие каждого урока — 3 вопроса.
