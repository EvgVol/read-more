# Iteration 04 — quiz и серверная проверка знаний

Статус: **DONE**

## Цель

Добавить к пилотному уроку проверку понимания, при которой результат рассчитывается на сервере, попытка сохраняется, а правильные ответы не попадают в HTML страницы.

## Что сделано

- Добавлены модели `QuizQuestion`, `QuizAttempt` и `QuizAnswer`.
- Поддержаны типы вопросов:
  - single-choice;
  - multiple-choice с частичными баллами;
  - short-answer с NFKC, casefold и нормализацией пробелов.
- Добавлен порог прохождения 80%.
- Каждая отправка создаёт отдельную попытку; ответы пользователя изолированы по user и lesson.
- Добавлен серверный endpoint отправки quiz.
- В trainer добавлена форма теста и экран результата с баллами, статусом и объяснениями.
- Добавлен идемпотентный `seed_ml_quiz` с тремя вопросами для каждого из четырёх уроков Python-модуля.
- Docker startup теперь последовательно запускает seed курса, материалов, блочного пилота и quiz; чистое развёртывание получает полный текущий пилот автоматически.
- Правильные ответы хранятся в модели и не сериализуются в шаблон.
- Quiz-вопросы загружаются через bounded prefetch без N+1.

## Проверки

- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **62 теста OK**.
- GET trainer первого урока — HTTP 200, quiz отображается, `correct_answers` отсутствует в HTML.
- POST с правильными ответами — создаёт попытку и возвращает результат через PRG-redirect.
- Повторный seed — 3 вопроса без дубликатов.
- Performance-тест trainer проходит с bounded prefetch quiz-вопросов.

## Данные

В рабочей базе опубликованы 12 вопросов: по 3 для каждого из четырёх уроков Python-модуля. Остальные 24 урока не получили quiz автоматически.
