# Iteration 13 — защищённая страница аудита курса

Статус: **DONE**

## Цель

Сделать редакторский отчёт доступным из интерфейса, чтобы владельцу курса не требовалось запускать management command вручную.

## Что сделано

- Добавлена защищённая страница:
  `/ru/course/ml-inzhener/audit/`.
- Страница доступна владельцу курса и staff-пользователям.
- Для студентов доступ закрыт, неавторизованные пользователи перенаправляются на страницу входа.
- В trainer добавлена ссылка «Отчёт качества курса» для владельца и staff.
- На странице отображаются:
  - статус аудита;
  - количество модулей, уроков и quiz-вопросов;
  - число уроков с замечаниями;
  - таблица по всем урокам с объёмом теории, практики, self-check и типами quiz;
  - раскрываемые детали ошибок по конкретному уроку.
- Добавлена адаптивная стилизация с горизонтальной прокруткой таблицы на узких экранах.
- Доступ к `owner` в trainer переведён на `select_related`, чтобы новая ссылка не добавляла N+1-запрос.

## Проверки

- Анонимный запрос к audit URL через nginx получает `302` на авторизацию.
- Владелец курса получает страницу со сводкой 7 модулей, 28 уроков и 84 quiz-вопросов.
- Студент получает `404` и не видит редакторский отчёт.
- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **69 тестов OK**.
- Performance-тест trainer снова проходит лимит в 22 запроса.
