# Iteration 05 — результат quiz в истории обучения

Статус: **DONE**

## Цель

Показать последнюю попытку quiz отдельно от пятишагового прогресса урока: процент, баллы и статус освоения должны сохраняться и возобновляться после перезапуска.

## Что сделано

- Trainer загружает последнюю попытку только текущего пользователя и текущего урока.
- В интерфейсе отображаются:
  - процент результата;
  - набранные и максимальные баллы;
  - статус «Освоено» или «Нужно повторить».
- Результат отделён от `LessonProgress`: просмотр и завершение этапа не превращают quiz в автоматически пройденный.
- Добавлены адаптивные стили блока последней попытки.
- Загрузка результата остаётся bounded: добавлен один запрос для текущего урока, без N+1 по вопросам.

## Проверки

- `python manage.py check` — без ошибок.
- `makemigrations courses --check --dry-run` — изменений схемы нет.
- `python manage.py test courses --keepdb -v 1` — **62 теста OK**.
- После отправки quiz отображаются «Последняя попытка» и «Освоено».
- После перезапуска контейнера последняя попытка и её результат сохраняются.
- Performance-проверка trainer проходит в bounded query budget.
